# 最終驗收規則

## 內容

- [ ] 製作前已完成整體故事線與逐頁規劃表，不是邊製作邊臨時想內容。
- [ ] 以實際提供的來源素材為準，舊 PPT 殘留敘述已清除；未強制要求長摘要。
- [ ] 來源文件圖表全部納入；缺圖已通過數據重繪、自製示意或聯網搜圖補足。
- [ ] 自製圖與外部圖性質、來源標註清楚，外部圖片已記錄網址與權利資訊。
- [ ] 故事線完整，每頁有核心判斷，沒有突然跳躍。
- [ ] 數值、單位、百分比、小數位與圖表一致，無數據時未虛構數據圖。
- [ ] 實測、推測、候選、代理與現場事實分清。
- [ ] 文獻與圖片來源真實可查，無虛構內容。

## 版式

- [ ] 全部白底、16:9，字體、顏色、邊距與頁眉頁腳統一。
- [ ] 每個主體頁都有承擔資訊功能的視覺元素，無連續純文字提綱頁。
- [ ] 頁面緊湊飽滿，有效內容充分利用主體區域，無大面積無意義空白。
- [ ] 緊湊由分欄、組塊與圖文對照實現，未靠縮小字體、壓縮行距或疊放物件硬塞。
- [ ] 技術路線與技術細節有圖，字體足夠大。
- [ ] 無文字重疊、異常換行、圖片變形、物件越界。
- [ ] 圖片之間無遮擋；應獨立的圖片與表格保持獨立可編輯。
- [ ] 圖表坐標、刻度、圖例、標題、色標與來源在 PDF 中可讀。

## 匯報

- [ ] 各頁秒數總和精確等於使用者指定時長；14 分鐘模板為 840 秒。
- [ ] 封面與結束頁短，方法、結果與保護對策佔主要時間。
- [ ] 非本專業聽眾能理解每頁為甚麼要做。
- [ ] 每頁有明確指圖順序與切換句，不逐字念頁面。
- [ ] 結論回答在哪裡、有多少、先核查甚麼。
