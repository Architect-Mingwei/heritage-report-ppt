# 先規劃、後製作：逐頁內容規劃規則

## 規劃是必經步驟

不得打開製作工具後才逐頁想內容。先完成整體敘事與逐頁規劃，通過規劃檢查後才製作。使用者要求「直接完成」時，仍須在內部完成規劃，只是不必等待其確認。

## 第一步：確定匯報任務

先寫清：

- 目標聽眾及其已有知識。
- 匯報時長、場合與預期聽眾記住的一句話。
- 可用素材及其證據範圍；長摘要不是必要輸入。
- 研究或項目的核心問題、主要方法、最重要結果與行動意義。
- 必須保留的限制、候選屬性與不確定性。

## 第二步：安排因果故事線

為每一階段回答「為甚麼下一步必須出現」。常用順序為背景→對象→問題→缺口→研究問題→方法→數據→結果→綜合判讀→建議→結論，但可依時長合併或拆分。

刪除不能支持核心判斷的支線，合併重複頁，拆分資訊過密頁。不要按來源文件的段落順序機械搬運。

## 第三步：建立逐頁規劃表

每頁必須填寫：

| 欄位 | 要求 |
|---|---|
| 頁碼與秒數 | 各頁秒數加總精確等於目標時長 |
| 本頁功能 | 在故事中承擔甚麼作用 |
| 結論式標題 | 讓聽眾只看標題也知道本頁重點 |
| 核心句 | 一個主要判斷，不堆多個中心 |
| 內容組塊 | 通常 2–4 組，列明取捨與先後 |
| 視覺證據 | 圖、表、照片、地圖、流程或示意圖的具體內容 |
| 視覺來源 | 現有素材、原始數據重繪、自製或聯網搜尋 |
| 版式草圖 | 左右分欄、卡片、流程、2 × 2 等，以及各區比例 |
| 指圖順序 | 台上先看哪裡、再看哪裡 |
| 意義與切換 | 本頁為甚麼重要，如何自然进入下一頁 |

## 圖文並茂的硬性要求

- 每個主體內容頁至少有一項承擔資訊功能的視覺元素；不得連續出現純文字提綱頁。
- 圖必須回答問題，不能用無關照片、裝飾圖標或科技背景充數。
- 主體頁的視覺區原則上佔主體區域約 40%–65%；證據密集型結果頁可更高。
- 文字負責判斷與解釋，圖表負責證據與關係；二者不得只是重複同一句話。
- 技術路線必須是圖文流程；技術細節必須有方法架構或機制示意；結果頁必須有數據圖、空間圖、照片或可編輯表格。
- 缺圖時立即指定重繪、自製或聯網搜尋方案，不得先做成純文字頁再留到最後補圖。

## 緊湊而不擁擠

- 每頁保留「核心句＋主要證據＋導讀／意義＋切換」，避免大面積無意義空白。
- 主體區域應被有效內容充分利用，但保留固定邊距、欄間距與圖片間距。
- 緊湊通過分欄、組塊、並列證據與圖文對照實現，不通過縮小字體、壓縮行距或疊放物件實現。
- 若內容超出頁面，優先刪除次要資訊、改變圖型或拆頁；不得讓文字壓圖、圖片互蓋或表格越界。
- 若頁面過空，優先放大圖表、補充讀圖引導、方法條件或管理意義，而不是加裝飾。

## 規劃通過條件

製作前確認：

- [ ] 整體只有一條清楚主線，每頁都有不可替代的功能。
- [ ] 每頁有結論式標題、核心句與明確視覺證據。
- [ ] 來源文件圖表全部有位置，缺圖已有具體補圖方案。
- [ ] 每頁已指定版式與指圖順序，主體頁無純文字提綱。
- [ ] 沒有內容重複、突然跳躍、明顯過空或過密頁。
- [ ] 各頁秒數總和精確等於目標時長，方法與結果獲得足夠時間。
- [ ] 所有內容均有素材依據，沒有虛構數據、結果或來源。
